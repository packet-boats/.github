**We build the boats.<br>You chart the routes.**

English · [简体中文](https://github.com/packet-boats/.github/blob/main/profile/README.zh-CN.md)

Packet Boats builds self-hosted software for running your own network routes. It runs on servers you own, and your traffic never passes through us. Our first product, Catboat, is in development. A catboat is a small sailboat with one mast and one sail, simple enough for one person to handle.
