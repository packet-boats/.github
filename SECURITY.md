# Security policy

Please report a security problem in any Packet Boats project privately,
by email to [contact@packet.boats](mailto:contact@packet.boats), not in a
public issue, discussion or pull request.

Say what you found, how to reproduce it, and which versions it affects.
We reply to every report, agree with you when the problem can be made
public, and say in the release notes which release fixes it. Fixes go
into the newest release of each project.

Chantey is built from sing-box's source. If a problem is in sing-box
itself rather than in Chantey's patches, please report it to sing-box's
authors too.
